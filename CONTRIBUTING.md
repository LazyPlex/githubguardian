# Contributing

Thanks for contributing to GitHub Guardian.

## Development principles

- Keep changes focused and testable.
- Never commit real credentials or secrets.
- Add tests for new detectors and security-sensitive behavior.
- Do not include live secret values in issues, pull requests, fixtures, or documentation.
- Prefer false-positive-resistant detection over noisy pattern matching.

## Pull requests

Please explain:

1. What changed
2. Why it changed
3. How it was tested
4. Any security or privacy implications
